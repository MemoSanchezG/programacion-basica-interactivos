    ¿Qué tipo de error tiene?

    Repasa las definiciones
    Error sintáctico
    El código viola las reglas del lenguaje; el intérprete ni siquiera puede empezar a ejecutarlo.
    Error semántico (o de ejecución)
    La sintaxis es válida, pero algo falla al ejecutar una instrucción concreta.
    Error lógico
    El programa corre de principio a fin sin ningún mensaje de error, pero produce un resultado incorrecto porque el algoritmo está mal planteado.
