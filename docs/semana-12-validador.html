Valida las lecturas de una red de sensores

Escribe validar(lectura) para separar las lecturas buenas de las que llegaron mal de la API, sin que tu programa se detenga.

Instrucciones

  1. Doce estaciones del área metropolitana mandaron su lectura por una API. json.loads ya convirtió el texto en la lista lecturas. Ejecuta primero el código tal cual: ¿todas son buenas?
  2. Completa validar(lectura). Debe regresar {"estacion": ..., "temp": ..., "humedad": ...} con temp como float y humedad como int, o lanzar un error:
    • estacion: texto que no esté vacío.
    • temp: un número que no sea bool. Si llegó como texto ("24.6"), repáralo con float(); si el texto no se puede convertir, lanza tu propio ValueError.
    • humedad: un entero (int, no bool) de 0 a 100.
  3. Si falta un campo o el valor es imposible, raise ValueError(...); si llegó otro tipo, raise TypeError(...). El mensaje debe decir el campo; conviene que diga también la estación y el valor que llegó ({valor!r}).
  4. En el ciclo usa try/except: guarda en errores el mensaje de cada lectura mala y sigue con la siguiente (registrar y continuar).
  5. Al final imprime el promedio de temp de las lecturas válidas, redondeado a 2 decimales: Promedio: ...

Lo que se revisa al presionar Verificar

    Pista: revisa cada campo en este orden: que exista (in), que sea del tipo correcto (primero isinstance(x, bool), porque True también es int) y que el valor tenga sentido (el rango). float("24,8") lanza ValueError: atrápalo con try/except y lanza el tuyo con el nombre del campo.
