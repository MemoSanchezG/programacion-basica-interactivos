    1. Con python main.py, escribe import conversiones y en la línea 2 print(c_a_f). Después cambia la línea 1 a from conversiones import c_a_f. ¿Qué nombre crea cada forma en main.py?
    2. Con import conversiones, elige python scripts\grafica.py y después python clima\main.py (desde Documents). ¿De qué depende que Python encuentre conversiones.py: de la carpeta donde estás o de la carpeta del archivo que corres? ¿Cuánto vale sys.path[0] en cada caso?

    4. Escribe from conversiones import * y en la línea 2 print(_redondear). ¿Por qué no llegó _redondear?
    5. Prueba import datos (la carpeta de datos no tiene __init__.py) y luego import datos.septiembre. ¿Qué pasa en cada caso y por qué?
