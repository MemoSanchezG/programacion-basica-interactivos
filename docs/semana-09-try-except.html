    Para explorar

    1. El bloque completo, "Archivo que no existe". ¿Por qué nunca aparece el mensaje Personas:?
    2. "Archivo con texto". ¿El archivo se cierra antes o después de que Python revise los except? Fíjate en f.closed.
    3. "Una carpeta". ¿Qué except atrapa el error? ¿Qué pasaría con los demás escenarios si except Exception estuviera antes que los otros except?
    4. raise, "No alcanzan". ¿Por qué el except ValueError no atrapa el ValueError que lanza apartar? ¿Qué cambiarías para que sí lo atrape?
    5. "No alcanzan". ¿Qué sale primero, "Gracias por tu visita" o el traceback? ¿Por qué nunca se imprime "Siguiente cliente"?
    6. return con finally. Si return se ejecuta antes que el finally, ¿por qué "Revisé ..." sale antes que "Precio guardado: ..."?
    7. raise, "Un número raro". El programa no se detiene, pero ¿está bien el resultado? ¿Qué regla le falta a apartar?
