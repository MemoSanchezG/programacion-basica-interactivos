Bits, ASCII y UTF-8

Prende y apaga bits para formar números, mira cuántos bytes ocupa cada letra en UTF-8 y descubre por qué a veces la ñ de "año" aparece como dos caracteres raros.

Un byte: 8 bits

Toca un bit para prenderlo (1) o apagarlo (0). Cada uno vale una potencia de 2.

Los bits marcados en guinda son las marcas de UTF-8: el primer byte dice cuántos bytes tiene el carácter (110 = 2, 1110 = 3, 11110 = 4) y los siguientes empiezan con 10.
