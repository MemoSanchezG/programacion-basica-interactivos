Proyecto modular: del archivo único a tres módulos

Un reporte del clima escrito en un solo archivo: repártelo en calculos.py, reporte.py y main.py con los imports correctos, córrelo aquí mismo y verifica.

Instrucciones

  1. Presiona ▶ Ejecutar: main.py tiene todo el programa, con dos pruebas rápidas sueltas y el reporte.
  2. Pasa UMBRAL_CALOR, UMBRAL_LLUVIA, oscilacion y tipo_de_dia a calculos.py. Las pruebas rápidas (los dos print) van en calculos.py, dentro de if __name__ == "__main__":.
  3. Pasa encabezado y renglon a reporte.py.
  4. En main.py borra lo que pasaste, importa los dos módulos y usa sus nombres: calculos.oscilacion(...), reporte.renglon(...), calculos.UMBRAL_CALOR. Los datos (DIAS, TMAX, TMIN y LLUVIA) se quedan en main.py.
  5. Mete el programa de main.py en una función main() y llámala dentro de if __name__ == "__main__":.
  6. Presiona ✓ Verificar. Para ver las pruebas rápidas, elige calculos.py en "Correr" y ejecuta.

Lo que se revisa al presionar Verificar

    Pista: cuando main.py importa calculos, Python ejecuta calculos.py completo, de arriba hacia abajo: un print suelto en ese archivo aparecería en medio del reporte.
