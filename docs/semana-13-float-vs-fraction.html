De un float a una fracción sencilla

limit_denominator paso a paso

Python recorre la fracción continua del float: cada renglón es una aproximación (convergente) mejor que la anterior. Se detiene cuando el denominador pasaría del máximo y elige la más cercana entre la última convergente y una intermedia.

Para explorar

  1. Antes de calcular: ¿qué imprime Fraction(6, 8)? ¿Y Fraction(4, 2)? ¿Y su repr?
  2. Suma 1/3 + 1/6 a mano con el MCD y compara con la calculadora.
  3. Multiplica Fraction(1, 2) por 0.5 usando "B sin Fraction". ¿De qué tipo es el resultado? ¿Y si sumas el int 1?
  4. Con π: ¿desde qué max_denominator aparece 22/7? ¿Y 355/113? ¿Cuántos decimales de π acierta cada una?
  5. Con 0.1 y max_denominator = 5, ¿qué fracción sale? ¿Por qué no 0?
  6. ¿Por qué Fraction(1 / 3).limit_denominator() da 1/3 aunque Fraction(1 / 3) no sea 1/3?
