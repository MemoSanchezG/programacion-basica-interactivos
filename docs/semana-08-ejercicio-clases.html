Una clase Estacion

Escribe una clase para una estación meteorológica que guarda sus lecturas de temperatura, córrela aquí mismo y verifica que cada estación lleve sus propios datos.

Instrucciones

  1. Presiona ▶ Ejecutar: la clase todavía no hace nada, así que todo imprime None.
  2. Completa __init__: guarda nombre y ciudad como atributos (con self.) y empieza self.lecturas como una lista vacía.
  3. Completa los métodos:
    MétodoQué hace
    registrar(temperatura)Si está entre -40 y 60 °C (incluidos), la agrega a las lecturas y regresa True; si no, no la agrega y regresa False.
    ultima()Regresa la última lectura, o None si todavía no hay.
    cuantas()Regresa cuántas lecturas tiene.
  4. Opcional: agrega __str__ para que print(fcfm) muestre Estación FCFM en San Nicolás.
  5. Presiona ✓ Verificar.

Lo que se revisa al presionar Verificar

    Pista: todo lo que es de cada estación se crea dentro de __init__ con self.; dentro de los métodos, los atributos también se usan con self. (self.lecturas).
