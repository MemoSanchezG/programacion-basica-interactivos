Cómo usar la IA esta semana

Graficar con IA sin que piense por ti

  • Una IA genera en segundos el código de una gráfica vistosa, pero no sabe qué pregunta quieres responder con ella ni si tus datos están limpios.
  • Primero tú: decide qué quieres mostrar (comparar, distribución, tendencia, relación) y elige el tipo de gráfica.
  • Después la IA: pídele que te explique un parámetro (bins, marker, figsize) o cómo hacer más legible tu gráfica.
  • Temario (Fase 3): la IA puede sugerir formas de graficar, pero no debe generar gráficas sin que entiendas los datos.

import matplotlib.pyplot as plt
import numpy as np

xs = np.linspace(-2, 5, 200)
f = xs**2 - 3*xs + 2
df = 2*xs - 3

plt.figure(figsize=(6, 3.6))
plt.plot(xs, f, label="f(x) = x² − 3x + 2")
plt.plot(xs, df, label="f'(x) = 2x − 3")
plt.axhline(0, color="gray", linewidth=0.8)
plt.axvline(1.5, color="gray", linestyle="--")
plt.title("Donde f' vale 0, f tiene su mínimo")
plt.legend()
plt.grid(True)
plt.show()

import json
import matplotlib.pyplot as plt
from openpyxl import Workbook
from openpyxl.drawing.image import Image

with open("clima_septiembre.json", encoding="utf-8") as f:
    clima = json.load(f)
dias = [int(r["fecha"][-2:]) for r in clima]
tmax = [r["tmax"] for r in clima]

fig, ax = plt.subplots(figsize=(5, 2.6))
ax.plot(dias, tmax, marker="o", color="#8C1D35")
ax.set_title("Máxima diaria, septiembre 2026")
ax.set_xlabel("Día")
ax.set_ylabel("°C")
fig.savefig("tmax.png", dpi=80, bbox_inches="tight")

libro = Workbook()
hoja = libro.active
hoja.title = "Gráficas"
hoja.add_image(Image("tmax.png"), "A1")
