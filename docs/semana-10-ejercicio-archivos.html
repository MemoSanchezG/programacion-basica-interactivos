Del CSV al reporte: resumen en JSON y amplitud en CSV

Lee el clima de Monterrey de septiembre de 2026 desde un CSV, convierte los datos y guarda un resumen en JSON y otra tabla en CSV, dentro de la carpeta reportes.

Instrucciones

  1. Ejecuta el código tal cual: lee clima_septiembre.csv con csv.DictReader. ¿Por qué '35.0' sale entre comillas?
  2. Crea la carpeta reportes con carpeta.mkdir(exist_ok=True) y convierte tmax, tmin y lluvia_mm de cada fila a float.
  3. Completa los None del diccionario resumen (sin cambiar sus claves ni su orden):
    • dias: cuántos días hay (int);
    • tmax_promedio: promedio de las máximas, con round(..., 2);
    • lluvia_total_mm: la lluvia del mes, con round(..., 1);
    • dias_con_lluvia: lista con las fechas de 1.0 mm o más;
    • mas_caluroso: {"fecha": ..., "tmax": ...} del día con la máxima más alta.
  4. Guárdalo en carpeta / "resumen.json" con json.dump(..., indent=2, ensure_ascii=False).
  5. Con csv.writer (y newline=""), escribe carpeta / "amplitud.csv" con el encabezado fecha,tmax,tmin,amplitud y una fila por día; amplitud es tmax - tmin con round(..., 1).

El archivo de la carpeta

Aquí las rutas se imprimen con / (reportes/resumen.json) porque Python corre en el navegador, como en Linux; en Windows salen con \. Y si falta un archivo, aquí el error dice [Errno 44]; en tu computadora, [Errno 2].

Lo que se revisa al presionar Verificar

    Pista: del CSV todo llega como texto: float(fila["tmax"]). Para el más caluroso, recorre las filas y quédate con la de mayor tmax. Arma las rutas con /: carpeta / "resumen.json". Después de ejecutar, abre "Ver contenido" de cada archivo para revisarlo.
