# Simuladores y ejercicios de Programación Básica

Sitio público del curso Programación Básica (FCFM-UANL): simuladores, ejercicios con Python en el
navegador y hojas del estudiante, ordenados por semana.

https://memosanchezg.github.io/programacion-basica-interactivos/

Este repositorio solo contiene lo publicado (carpeta `docs/`, servida por GitHub Pages). Se genera
con `presentaciones/simuladores/publicar.py` desde el repositorio del curso; no se edita a mano.
